
NetherQuests
=======

Ever wanted a Questing Mod simpler then other?
Then look no further, because this is the for you!

Features:
============
- Reward/Completion Types:
  - Item
  - XP
  - Advancement
  - Command (Only Reward)
- Pinging Quests
- Dependencies on other quests
- and many more...



How to use:
==========
To edit use /netherquests edit to unlock editing
Create, Edit & Delete Chapters and Quests
NEW CONFIG
Change almost everything
